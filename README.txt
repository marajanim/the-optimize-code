THE OPTIMIZE CODE WORDPRESS THEME
=================================

Installation
------------
1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Upload the-optimize-code-wordpress-theme.zip and activate it.
3. Visit Settings > Permalinks and click Save Changes once.

Theme pages
-----------
- The original design is used automatically on the site front page.
- Testing and Gallery pages are created automatically on first activation.
- Existing CSS, JavaScript, responsive rules, images, animation, light/dark mode,
  mobile navigation, and gallery lightbox are included unchanged.

Notes
-----
- The newsletter form preserves the original front-end confirmation behavior.
  Connect it to your preferred email or CRM provider before collecting live leads.
- Social links and the PGx email link are located in the theme templates.
- Standard WordPress pages and posts use a matching fallback layout.
